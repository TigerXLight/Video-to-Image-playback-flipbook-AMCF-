# Source frame smoke input

This folder is reserved for deterministic generated source frames used by the AMCF source-frames-to-digital smoke demo.

Run `python demo/generate_sample_source_frames.py` to generate a small standard-library PPM frame set and `source_frames_manifest.json`.

The generated frames are synthetic smoke-test input only. They are not physical proof, hardware validation, final UI output, or arbitrary real-world video ingestion.
