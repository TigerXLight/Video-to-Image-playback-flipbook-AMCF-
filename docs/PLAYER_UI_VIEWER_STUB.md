# Player UI Viewer Stub

The HTML viewer displays AMCF Player UI JSON state:

- reconstructed playback status
- current section
- section timeline
- reader/cartridge status
- validation status
- component payloads
- alpha/object mask status
- transform metadata
- residual/tile payload status
- validation log rows
- fail-closed decisions

It is useful for inspecting virtual hardware/player handoff state. It is not final UI, not playback proof, and not hardware validation.
