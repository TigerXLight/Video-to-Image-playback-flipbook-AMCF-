# Physical Player Visual Reference Note

Earlier screen/tablet-style physical-player images are superseded for the physical-player definition.

They may remain useful only as high-level software/path visuals or as references for the AMCF software Player UI. They must not define the physical player.

Corrected physical-player visuals must show mechanical/optical physical playback, not digital monitor playback. A corrected physical-player visual should emphasize indexed AMCF physical media, controlled transport, a fixed view gate, illumination/backlight/front light, an optical window or projection path, and optional reader/recovery lane if shown.

The physical reader image remains a reader/scanner visual reference only. It supports the cartridge/reader/scan-gate direction, not physical-player proof.

The AMCF Player UI image remains software/UI reference only. It supports player-facing state, validation log, timeline, and component payload inspection, not the physical-player mechanism.

No image is proof, CAD, final UI, hardware validation, physical Level 5, manufacturing plan, or prototype evidence.
