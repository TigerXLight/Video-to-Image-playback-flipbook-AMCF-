# Motion Truth Diagnostics Parity

The local `Test 03M` runner introduced a camera-compensated residual-motion audit. It separated global camera movement from local motion and drew named zones over the frame. The result included `diagnostic_zone_motion_overlay.mp4`, motion-zone metrics, component-coverage diagnostics, and a human review rule. The later `03N`/`03S` runs used the audit to correct the waterfall, foliage, transient-person, and static-background component map.

The public `src/amcf_motion_truth_diagnostics.py` ports the reusable pixel operations from the 03M runner: sparse Lucas-Kanade feature tracking with affine RANSAC, Farneback median-translation fallback, camera-compensated residual masks, the original zone-motion thresholds, per-zone metrics, and the zone overlay. `src/amcf_diagnostic_profiles.py` now adds the accepted project profiles: the seven historical 03M waterfall zones, the exact 08E Farneback/TURBO motion-heat contract, and the conservative 12E reviewed proxy renderer. Dimensions and source-specific inputs remain explicit. OpenCV and NumPy are optional dependencies; importing the modules works without them, and diagnostic calls give a clear error when they are absent.

Run `python demo/run_amcf_motion_truth_diagnostics_demo.py` to process two deterministic synthetic frames. It writes `motion_truth_report.json` and `zone_motion_overlay.png` under `output/amcf_motion_truth_diagnostics_demo/`. The test suite checks actual motion detection, camera-translation compensation, invalid-zone rejection, and the original 03M threshold behavior.

Run `python demo/run_amcf_diagnostic_profiles.py --help` for the profile CLI. The unified Main acceptance runner now emits a full 03M-style zone-motion video plus a pair heat image, while the profile CLI can render the full 08E truth/decoded heat comparison or a reviewed 12E proxy without copying historical media into Main. The profile layer deliberately does not import the SAM2 tracking stack, claim semantic masks, or promote proxy boxes into object truth. The original 03M report warns that camera registration can be imperfect and requires review against the source video. No final tracking, decoded-video, or full local-workspace parity is claimed by these diagnostics.
