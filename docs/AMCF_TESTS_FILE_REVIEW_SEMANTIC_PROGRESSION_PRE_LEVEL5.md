## Scope

This batch reviews the nine semantic/proxy folders immediately older than the accepted controlled and HOOT proof runs:

1. Tower Bridge proxy generalisation and source ROI preparation;
2. Tower Bridge proxy reconstruction and benchmark;
3. tool search and segmentation/tracking survey;
4. local deep semantic toolchain integration;

6. deep SAM2/CoTracker Level 5 retry;

8. high-precision mask cluster and object-identity promotion;
9. lost/recovered and full semantic closure.

The folders contain 2,736 files in total. Their media and reports are progression evidence, not a second public archive format.

## Actual Code Findings

The inspected runners use combinations of OpenCV, NumPy, Pillow, FFmpeg, Torch, SAM2, CoTracker, network downloads, local checkpoints, source video paths, and generated media. Several runners also write their own run folder and copy themselves into output. None is a clean standard-library public module suitable for direct copying without a dependency/provenance/configuration phase.

The public repo already contains the safe reusable abstractions needed by the accepted public workflow:

- `src/amcf_video_pipeline.py` for bounded video/frame ingestion;
- `src/amcf_component_event_archive.py` for component-event archives and reconstruction;
- `src/amcf_quality_metrics.py` for bounded quality checks;
- `src/amcf_optical_flow_tracking.py` for optional tracking reports;
- `src/amcf_semantic_sidecar_overlay.py` for sidecar inspection and claim-safe overlay reporting;
- `src/amcf_semantic_level5_proof.py` for the accepted controlled/HOOT proof index;
- `src/amcf_motion_truth_diagnostics.py` and `src/amcf_test02_diagnostic_viewer.py` for public diagnostics/viewer behavior.

These are public-safe ports or newer equivalents, not claims that the original deep model runs are reproduced without their data and dependencies.

## Progression Answer

Yes, these folders show progression across time. A failed/parked method in an older folder was not automatically the final method; later folders reused selected evidence, added stricter gates, or replaced the approach. In particular:

- Tower Bridge proxy work established scale, residual, and ROI evidence but did not close semantic Level 5.
- SAM2/CoTracker bridge work established machine candidates and a possible sidecar contract but did not close semantic Level 5.
- high-precision and mask-track work strengthened candidate validation but deliberately kept full semantic claims false.
- the lost/recovered closure run found candidates but rejected them after visual/semantic review.
- the later controlled and HOOT folders are the accepted bounded vectors.

## Claim Boundary

- public semantic/object Level 5 is accepted only for the controlled canonical and HOOT dataset-annotated vectors;
- hardware validation claimed: false;
- physical Level 5 claimed: false;
- manufactured player claimed: false;
- real motors, sensors, cartridges, printers, scanners, USB, or serial hardware: not claimed;
- `unsafe_acceptance_count`: 0 in the public proof/report layers;
- generated output committed: no.

## Remaining Gap

Exact reproduction of the deep local runners remains an optional parity gap. Closing it would require an explicitly approved dependency/provenance phase with configurable checkpoints, bounded fixtures, and reproducible acceptance reports. It should not be done by copying private checkpoints or generated media into the public repo.
