# AMCF GitHub Pages site

This folder contains a static GitHub Pages landing site for the AMCF public repository.

It is documentation/context only. It does not change AMCF runtime functionality, does not claim hardware validation, and does not claim physical proof.

Files:

- `index.html`
- `styles.css`
- `.nojekyll`
- `assets/amcf_mechanical_optical_physical_player_concept.svg`

The workflow at `.github/workflows/pages.yml` publishes this folder with GitHub Pages official actions.

The site embeds the current mechanical/optical physical-player concept diagram directly so the public Pages view has a visible physical-player reference. The current preferred framing is a dynamic folded-path A/B staged indexed-section player, not a fixed-FPS page machine, not a long straight roller path, and not a normal digital-screen player. The diagram is concept/context only, not physical proof, not hardware validation, and not a manufactured prototype.

The site should describe digital AMCF as the canonical AMCF representation, scheduler, and validation model. Physical AMCF should be described as the material embodiment of the same AMCF timing/update structure: the reader path recovers or verifies physical AMCF back into digital AMCF, and the player path physically/optically presents AMCF media according to the same dynamic update schedule.
