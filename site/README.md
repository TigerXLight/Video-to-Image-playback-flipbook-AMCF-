# AMCF GitHub Pages site

This folder contains a static GitHub Pages landing site for the AMCF public repository.

It is documentation/context only. It does not change AMCF runtime functionality, does not claim hardware validation, and does not claim physical proof.

Files:

- `index.html`
- `styles.css`

The workflow at `.github/workflows/pages.yml` publishes this folder with GitHub Pages official actions.
