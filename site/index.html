Mixed-licence, source-available AMCF research repository

Software-first AMCF runtime with virtual physical-media support.

AMCF demonstrates a standard-library software path from generated source frames to AMCF digital archives, indexed physical-carrier packages, virtual reader recovery/export, software support for future reader/printer-style physical-output paths, and a dynamic folded-path A/B mechanical/optical physical-player simulator.

Digital AMCF is the canonical AMCF representation, scheduler, and validation model. Physical AMCF is the material embodiment of the same AMCF timing/update structure: readers recover or verify physical AMCF back into digital AMCF, while players physically/optically present AMCF media according to the same dynamic update schedule.

AMCF overview

AMCF is a software-first research package for representing video-like source material as indexed AMCF digital state, validating that state, preparing physical-carrier-style output for future printer/physical-output paths, and simulating future reader/player behavior without requiring manufactured hardware.

Functional software path

  1. Generated source frames become an AMCF digital archive.
  2. The archive is validated with manifests, payloads, and hashes.
  3. AMCF digital state can be handed to software playback/viewer state.

Demos and tests

The package includes demos for source-frame encoding, physical-carrier package generation, virtual reader recovery/export, virtual hardware support, and mechanical/optical player simulation. The tests cover archive integrity, fail-closed validation, carrier lanes, recovery, and simulator controls.

Physical carrier, printer/prep, and reader/recovery path

AMCF digital archives can generate software carrier packages with indexed sections, timing/index, registration, payload, colour registry, metadata, and hash/checksum lanes. The shared Physical I/O Architecture uses one AMCFPhysicalManifest for future printer output, reader recovery, and player control/recognition paths. This is printer/physical-output preparation support in software, not real printing. The virtual reader path reads generated carrier sections, validates them, and exports recovered frame payloads.

Mechanical/optical physical-player simulator

The simulator models indexed sections moving through a compact folded-path A/B staged transport: current section at the visible view gate, next section in a hidden preload gate, shutter/illumination blanking during transition, reader prefetch, index lock, and play, pause, step, reverse, and seek controls. It is a software simulation of a future mechanical/optical player that executes the digital AMCF schedule physically/optically; it is not real physical playback.

Concept assets

The repository includes current and legacy concept references under assets/concepts/. The corrected physical-player concept defines the current physical playback direction: indexed media, folded A/B staging, fixed view/playback gate, shuttered illumination, optical path, and direct human viewing. Older diagrams are retained as context and may be superseded.

Physical Player Software-Control Simulator

The physical-player branch documents and simulates the software/control architecture for a future mechanical/optical AMCF player. It includes deterministic state-machine, fail-closed, reverse/seek, mechanism-profile, integrated-demo, release-review, package-inventory, final-review, closeout-handoff, and release-tag-prep layers. It does not claim manufactured hardware or physical validation.

AMCF Software I/O Control Baseline

The software I/O branch documents and tests no-hardware software paths for PC to Printer, PC to/from Reader, and Player to/from PC. It includes shared package and manifest models, cross-corridor reporting, deterministic fixtures, abstract print layout, simulated reader recovery, simulated player-control bridge, roundtrip reporting, and mutation safety tests. It does not claim hardware validation, physical Level 5 completion, or manufactured player completion.
