AMCF overview

AMCF is a software-first research package for representing video-like source material as indexed AMCF digital state, validating that state, preparing physical-carrier-style output for future printer/physical-output paths, and simulating future reader/player behavior without requiring manufactured hardware.

Functional software path

  1. Generated source frames become an AMCF digital archive.
  2. The archive is validated with manifests, payloads, and hashes.
  3. AMCF digital state can be handed to software playback/viewer state.

Demos and tests

The package includes demos for source-frame encoding, physical-carrier package generation, virtual reader recovery/export, virtual hardware support, and mechanical/optical player simulation. The tests cover archive integrity, fail-closed validation, carrier lanes, recovery, and simulator controls.

Physical carrier, printer/prep, and reader/recovery path

AMCF digital archives can generate software carrier packages with indexed sections, timing/index, registration, payload, colour registry, metadata, and hash/checksum lanes. This is printer/physical-output preparation support in software, not real printing. The virtual reader path reads those generated carrier sections, validates them, and exports recovered frame payloads.

Mechanical/optical physical-player simulator

The simulator models indexed sections moving through a compact folded-path A/B staged transport: current section at the visible view gate, next section in a hidden preload gate, shutter/illumination blanking during transition, reader prefetch, index lock, and play, pause, step, reverse, and seek controls. It is a software simulation of a future mechanical/optical player, not real physical playback.

Concept assets

The repository includes current and legacy concept references under assets/concepts/. The corrected physical-player concept defines the current physical playback direction: indexed media, folded A/B staging, fixed view/playback gate, shuttered illumination, optical path, and direct human viewing. Older diagrams are retained as context and may be superseded.

Claim boundaries

This site and repository do not claim strict OSI open source for the whole repo, arbitrary real video ingestion, MP4 export, real physical printing, real scanner hardware, actual physical scanning, real physical playback, hardware validation, physical proof, final UI, or a manufactured prototype.
